# ML-Engineering

Industrial software and data platforms for manufacturing. We connect the plant floor with the systems around it: MES, SCADA, historians, and the applications operators use.

[ml-engineering.nl](https://ml-engineering.nl) · Beneden-Leeuwen, the Netherlands

## What we build

- Manufacturing execution systems and production workflows
- AVEVA System Platform models and reusable object templates
- Historian and industrial data layers
- Edge-to-cloud connectivity and API gateways
- Full-stack applications in C#, TypeScript, and Node.js
- SQL Server and PostgreSQL for process, quality, and genealogy data
- Flutter apps for operations visibility

## How we work

Long-lived systems, clear boundaries, and observability from the start. That covers a single production line and an enterprise MES data platform.
