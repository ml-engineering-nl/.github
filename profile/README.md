# ML-Engineering

Industrial software and data solutions for manufacturing. ML-Engineering bridges operations technology and information technology, from a single production line dashboard to an enterprise MES data platform.

[ml-engineering.nl](https://ml-engineering.nl) · Remote / Europe · [info@ml-engineering.nl](mailto:info@ml-engineering.nl)

Available for project delivery, architecture reviews, optimization work, and leadership support.

## What we deliver

- [MES systems](https://ml-engineering.nl/mes-systems): production workflows, quality gates, lots, batches, genealogy, electronic work instructions, SPC, and deviation tracking. ISA-95, historians, ERP (SAP / Dynamics), LIMS, and SCADA.
- [AVEVA System Platform](https://ml-engineering.nl/aveva-system-platform): object models, templates, and galaxy structures that follow real equipment hierarchies and roll out across sites.
- [Interfacing](https://ml-engineering.nl/interfacing): OPC UA, MQTT, Kafka, REST, GraphQL, file drops, and event pipelines between OT and IT, with schema governance and least-privilege hardening.
- [Programming](https://ml-engineering.nl/programming): operator interfaces and backend services in C# (ASP.NET Core), Node.js, and TypeScript. Nuxt/Vue, WebSockets, SignalR, OIDC, Azure AD, and Keycloak.
- [SQL Server and PostgreSQL](https://ml-engineering.nl/databases): schemas for process data, event logs, genealogy, quality, maintenance, and KPIs. Indexing, partitioning, CDC, and retention.
- [Flutter apps](https://ml-engineering.nl/mobile-apps-flutter): maintenance tasks, barcode and QR scanning, offline capture, operator logbooks, and production approvals.

## How the work is built

Layered architecture, clear domain boundaries, and observability from the start: metrics, logging, and traceability. The aim is a system that stays maintainable after the first release.
